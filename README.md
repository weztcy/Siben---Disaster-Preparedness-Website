# Siben - Disaster Preparedness Website

**Siben** is a disaster preparedness website developed using **JavaScript**, **React.js**, and **Bootstrap** to provide accessible information and guidance related to natural disasters.

The platform centralizes disaster management information, disaster data, disaster-related news, and weather forecasts within a responsive web interface.

## 🌍 About the Project

Siben was developed as an information platform designed to support public awareness and preparedness for natural disasters.

The website organizes disaster-related information into four main categories:

* Disaster Management
* Disaster Data
* Disaster News
* Weather Forecasts

External APIs are integrated to provide dynamic data and information across the platform.

## 🚨 Disaster Management

The Disaster Management section provides information and guidance related to disaster preparedness, response, and mitigation.

Content is structured to help users access relevant disaster-related information in a clear and organized format.

## 📊 Disaster Data

Disaster data is retrieved and managed through an API integration.

The platform presents disaster-related information dynamically, allowing data to be displayed and updated through an external data source.

## 📰 Disaster News

The website integrates disaster-related news through the **Detik.com API**.

News content is displayed within the application to provide users with access to recent information related to natural disasters and emergency events.

## 🌦️ Weather Forecasts

Weather forecast information is retrieved through the **BMKG API**.

This integration allows the website to provide weather-related information that can support situational awareness and disaster preparedness.

## 🔌 API Integration

Siben integrates multiple external data sources to provide dynamic information across the platform:

* Disaster Data API
* Detik.com API
* BMKG API

These integrations allow disaster data, news, and weather information to be presented through a centralized interface.
